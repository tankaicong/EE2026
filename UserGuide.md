Create Your Own Object Tracker

An educational object tracking system that allows users to interactively build an image processing pipeline (preprocessing → threshold → morphology), learn about the object detection algorithm and tune its parameters, before running a servo with PID control for object tracking. Users control it with a mouse and on-screen user interface, and visualize everything live through VGA adaptor. In addition to the Verilog designs, this system integrates the following hardware: 1x Basys3 FPGA, 1x OV7670 Camera, 2x MG90 Servo, 1x USB Mouse and 1x VGA display.
